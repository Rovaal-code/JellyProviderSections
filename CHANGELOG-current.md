JellyProvider Sections v0.1.3.0 - renamed

The plugin is now called **JellyProvider Sections**, everywhere: the plugin catalogue, the entry in the dashboard, the configuration page, the scheduled task, the log lines and the documentation.

Nothing to do on your side. The plugin is matched by its id, which has not changed, so the update lands on top of the old one and keeps every section, key and setting exactly as it was. The API routes, the configuration file and the section ids are all unchanged too.
